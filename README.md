# 🛡️ Google Cybersecurity Certificate — Projects

This repository contains the hands-on projects and case studies I completed as part of the **Google Cybersecurity Professional Certificate**. Each project applies core cybersecurity concepts — risk assessment, compliance frameworks, network security, and incident response — to realistic business scenarios.

---

## Projects

### 1. [Botium Toys — Internal Security Audit](./botium-toys-security-audit.md)
A full internal security audit for a fictional small business (Botium Toys), conducted using the **NIST Cybersecurity Framework**. Includes a scope and goals definition, asset inventory, controls and compliance checklist (PCI DSS / GDPR), findings, and prioritized recommendations.

**Skills demonstrated:**
- Security audits & risk assessment
- Regulatory compliance analysis (PCI DSS, GDPR)
- Security controls evaluation (technical, physical, administrative)
- Documentation and professional reporting

---

### 2. [Analyze Network Attacks](./Analyse-network-attacks.md)
Describing a security event requires presenting evidence and explaining how a conclusion was reached. This activity focuses on spotting patterns in logs and data to determine the source and type of a network attack — a core skill for responding to incidents quickly and efficiently.

**Skills demonstrated:**
- Incident response
- Network traffic analysis
- Attack type identification

---

### 3. [Apply OS Hardening Techniques](./OS-hardening-1.md)
Acting as a cybersecurity analyst for a company hosting the site `yummyrecipesforme.com`, this project investigates a security issue visitors experience when loading the main webpage — identifying, documenting, and recommending a solution.

**Skills demonstrated:**
- Security investigation
- OS hardening techniques
- `tcpdump` log analysis

---

### 4. [Network-hardening-Analysis](./network-hardening.md)
Following a major data breach that compromised customer personal information (names and addresses), this project outlines strong, repeatable network hardening practices to prevent future attacks and breaches.

**Skills demonstrated:**
- Network hardening strategy
- Breach analysis
- Preventive security controls
